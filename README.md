# Digital Logic Gate Simulator

A C program that simulates basic digital logic gates (AND, OR, NOT, XOR, and more).
Built as a hands-on project to apply concepts from Coursera's "C for Everyone" course.

## Features (in progress)
- Basic logic gates: AND, OR, NOT, XOR
- Truth table generator
- Circuit builder (combine multiple gates)
- Interactive menu

## How to run
```bash
gcc -o gates gates.c
./gates
```
